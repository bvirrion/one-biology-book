本书中的插图均为原创。照片依其各自的自由许可使用，谨向其作者致谢：

\begin{itemize}
  \item \emph{格雷戈尔·孟德尔}（减数分裂章节）：照片，19世纪，维基共享资源，公有领域。
  \item \emph{亚历山大·弗莱明}（抗生素耐药性章节）：照片，Imperial War Museum，1943年，经由维基共享资源，公有领域。
  \item \emph{从淋巴细胞出芽的艾滋病病毒}（适应性免疫章节）：电子显微照片，作者 C.~Goldsmith，美国疾病控制与预防中心，经由维基共享资源，公有领域。
  \item \emph{达尔文雀}（物种分化章节）：雕版画，John Gould，1845年，维基共享资源，公有领域。
  \item \emph{感觉小人}（运动章节）：插图，取自 OpenStax \emph{Anatomy and Physiology}，经由维基共享资源，CC~BY~3.0。
  \item \emph{查尔斯·达尔文}（系统发育树章节）：照片，Henry Maull 与 John Fox 拍摄，约1854年，维基共享资源，公有领域。
  \item \emph{爱德华·詹纳}（适应性免疫章节）：油画，Wellcome Collection，经由维基共享资源，CC~BY~4.0。
  \item \emph{始祖鸟化石}（共同祖先章节）：照片，作者 James L.~Amos，维基共享资源，CC0。
\end{itemize}

每张照片完整的来源链接和许可证 URL 均列于本书仓库中的
\texttt{images/\allowbreak book2/\allowbreak CREDITS.md} 以及 \texttt{images/\allowbreak book1/\allowbreak CREDITS.md}。

\bigskip
除照片与原创插图外，全书各章中约五十幅图为人工智能生成的插图，由 OpenAI 图像生成功能根据本书编辑撰写的提示词制作，并在收录前经过生物学准确性审校。每幅生成图像的完整提示词均记录于仓库中的
\texttt{images/\allowbreak book2/\allowbreak ai/\allowbreak PROMPTS.md}。
